# Fictional recommendation demonstration

These 12 films, people, organizations and ratings are invented. The files use the original movie and ratings column names. The fixture demonstrates input loading and rule construction. It produces different results from the recorded course experiments and does not provide the original movies expected by the hard-coded introductory queries.

For an isolated demo, place these three CSVs and the project’s existing `../db.pl` in a separate working directory. Point the repeated `path` assignments in a notebook copy to that directory, with a trailing separator. To see introductory queries produce results, use a fixture title such as `antenna at daybreak`. Skip the original Colab installation and Drive-mount cells when the local runtime is already prepared. Keep the original research ratings unchanged.
